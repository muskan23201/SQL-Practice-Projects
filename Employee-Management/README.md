# Employee Management – SQL Practice Project

## About This Project
This project contains SQL practice exercises based on employee management data.

## Objectives
- Analyze employee information.
- Calculate department-wise average salaries.
- Identify highest-paid employees.
- Practice SQL joins and subqueries.
- Use CTEs and window functions.

## Skills Used
- MySQL
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Joins
- Subqueries
- CTEs
- Window Functions

## Project Status
In Progress – Learning and practicing SQL through hands-on exercises.
